# personal-website

Source for [puriyamirza.com](https://puriyamirza.com): a directory of side projects, with case studies to come.

- Plain HTML, CSS and a little JavaScript. No build step.
- `index.html` is the homepage ("Almanac" design). Background column lines pulse one at a time.
- `img/` holds the homepage photos.
- `projects/` holds unlisted pages (noindex, set in `vercel.json`).

Deploys to Vercel on every push to `main`.
